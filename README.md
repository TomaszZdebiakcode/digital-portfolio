# Digital Portfolio

> A modern, interactive portfolio showcasing my work, technical skills, and development journey as a software engineer.

## Overview

Digital Portfolio is a production-oriented personal portfolio built to present my projects, technical experience, and approach to software development.

The project combines a modern frontend architecture with responsive UI, reusable components, internationalization, and an interactive visual experience.

## Tech Stack

- **Next.js** — React framework and application architecture
- **React** — Component-based UI development
- **TypeScript** — Type-safe application development
- **Tailwind CSS** — Utility-first styling and responsive design
- **Lucide React** — Interface icons
- **React Icons** — Brand and social media icons

## Architecture

The application is structured around reusable and maintainable components, with dedicated sections for:

- Hero
- About
- Projects
- Skills
- Contact
- Navigation
- Footer

Content is separated from presentation where possible, allowing the portfolio to support multiple languages without duplicating UI logic.

## Key Features

- Responsive design across desktop, tablet, and mobile
- Internationalization with English, Polish, and German
- Reusable React components
- TypeScript-based type safety
- Interactive project showcase
- Project-specific case studies
- External project and social media links
- Modern dark UI
- Accessible and responsive interface
- Production deployment with Next.js
